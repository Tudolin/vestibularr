# Marca Vestibularr

- `marca.html` / `marca.png`: prancha de identidade (logo, mascote Capitão Grafite e poses, cores, tipografia, tom de voz, aplicações).
- `svg/`: arquivos vetoriais finais (logo horizontal, empilhado, negativo, wordmark, ícone do app, mascote em 6 poses + negativo).
- `gerar.py`: gera todos os SVGs (mascote desenhado em código; wordmark em Fredoka Bold convertida em curvas):
  `python3 docs/brand/gerar.py docs/brand/fonts/fredoka-700.ttf docs/brand/svg`
